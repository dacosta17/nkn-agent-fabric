# Roadmap

## Phase 1 — verified execution substrate

- signed capability manifests
- signed quotes
- signed execution attestations
- deterministic domain validators
- evidence provenance and freshness
- quorum and Byzantine rejection
- NKN packet/session transport

Status: implemented in `v0.6.0`.

## Phase 2 — public protocol hardening

- permissionless capability discovery
- portable signed reputation receipts
- explicit operator identity model
- multi-region benchmark harness
- collusion and Sybil simulations
- source-correlation analysis

Status: next.

## Phase 3 — economic security

- escrowed task execution
- provider stake
- dispute receipts
- slashing policy experiments
- NKN-denominated settlement

Economic mechanisms will only be introduced after the verification assumptions are independently measured.

## Phase 4 — real deployments

Priority workloads:

1. intelligence verification/oracle;
2. security assessment;
3. distributed infrastructure observability;
4. DeFi pre-trade risk quorum;
5. policy-controlled automation.

Success criterion: external operators run independent agents and produce reproducible evidence without trusting the repository author.
